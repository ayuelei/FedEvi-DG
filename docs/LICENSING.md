# Code and data licensing

The repository owner has not yet selected a code license for this preparation-stage release. Do not interpret the repository being viewable as a general permission to reuse or redistribute it. This file is explanatory, not a license grant.

A code license is normally a root `LICENSE` text file, not a certificate to purchase or apply for. If the owner confirms MIT, the standard text can be obtained from [Choose a License](https://choosealicense.com/licenses/mit/) and the year/copyright holder completed. MIT permits commercial use, modification and distribution with preservation of the copyright and license notice; it is not a non-commercial restriction and it does not require academic citation by itself.

See [GitHub's repository licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository). Confirm ownership and preserve applicable third-party notices before selecting the release license. Dependency licenses and original dataset permissions remain separate.

No reference-repository code was copied as part of the packaging survey. Existing implementation files retain their method attribution. A final third-party provenance review is still a release check, not a claim already satisfied by adding a license file.
